# BarIAscore

Scores validados para cirugía bariátrica y metabólica. Página estática: todo el cálculo ocurre en el navegador y no se guardan datos de pacientes.

Cada score implementa la fórmula publicada que se cita en la app (sección "Fuentes y referencias"). Apoyo a la decisión clínica; no reemplaza el juicio del cirujano.
